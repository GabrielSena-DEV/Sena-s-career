# Site pessoal — Gabriel Sena

Modo Atleta / Dark Mode de Alta Performance.

## Rodar
```
python servidor.py
```
(ou abra o `index.html` direto no navegador)

## Editar
- **Projetos:** array `PROJETOS` no topo do `script.js` (enquanto vazio, mostra "Em obras...").
- **Níveis das linguagens:** array `SKILLS` no `script.js`.
- **Links de contato:** seção `#contato` no `index.html` (procure o `TODO`).
- **Cor de destaque:** `--accent` no topo do `style.css` (`#FF5722` laranja ou `#00FF66` verde).
- **Fotos:** coloque os originais numa pasta e rode `python otimizar_imagens.py <pasta>`.

## Publicar grátis
GitHub Pages, Netlify ou Vercel: basta enviar esta pasta.
